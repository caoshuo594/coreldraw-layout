# 墙面绘制与尺寸标注

用于按平面图和 CDR 模板批量绘制墙面，以及按参考图修改尺寸标注。以下接口与案例来自本机 CorelDRAW X8；先核实当前版本、模板及对象结构。无需为普通图文排版加载本文件。

## 从平面图确定实际尺寸

- 逐面建立 `编号、实际宽度mm、实际高度mm、尺寸来源、推定依据`。来源区分原图标注、对应墙面推定、图上比例估算；对应隔墙另一面或等深柱位可作为推定依据，不能只凭距离最近就套数值。
- 平面图中竖向标注也是平面墙长，展开成墙面矩形后通常作为宽度；不能误认成墙高。墙高从本次要求或模板回读。
- 缺尺寸时先核实对应关系；用户允许推定时继续处理并记录。只有独立长度无法合理确定、且影响执行时才询问。图上比例估算不能标成实测值，应明确近似符号及依据。
- 按用户要求将同一单元的编号从左到右排成一行。原图缺号或编号跨色块时保留原编号并说明，不自行补号或改号。
- 复制模板只复制样式，不代表复制相同宽度。为每面单独设置宽度；按已核实的比例换算定位。例如毫米文档 `WorldScale=10`，实际 2982×3700 mm 对应 API 298.2×370 mm。

## 标注形式和字体

先辨明用户要求的是外观类似尺寸工具，还是必须为原生关联尺寸对象。后者不可默默改成线段与文字组合。

2026-10-16 的具体要求是：尺寸文字 50 号、沿用默认尺寸字体；每排第一面标宽高，其余只标宽。小样核实本机默认尺寸字体为 Arial；设置为 `Text.Story.Font='Arial'`、`Text.Story.Size=[single]50` 后再回读。本次“50号”按 50 pt 执行，不作为其他任务的默认字号；默认字体也应在当前机器核实。

保持尺寸数字为实际毫米；标注中是否显示单位、整数精度、估算前缀，取用户参考。原生尺寸会受文档比例影响，不再手工乘一次；手工标注则直接使用尺寸表中的实际值。

### 已验证的可编辑矢量标注

当用户接受外观一致的可编辑标注，或者原生接口无法可靠设置且用户未要求原生对象时，可使用：一段可编辑文字、两段尺寸线、两段尺寸界线，组合成一个标注组。不要栅格化。

- 水平标注：数字置于墙宽正中，两段水平线在文字左右各留空隙；两端箭头落在墙宽端点。界线从墙顶附近延伸到尺寸线，并略微超出。
- 竖向标注：只为本次要求的墙面创建。文字旋转 90°，放在墙高正中；尺寸线在文字上下断开，箭头落在墙高端点。
- 文字设置字体、字号后再计算可见外框并居中；字体回退会改变宽度，不能沿用旧坐标。旋转后再定位竖向文字。
- 读取或小样核实默认箭头及线宽，不硬编码其他机器的箭头索引。该次小样为箭头索引 89、线宽 0.0762 API mm；最终矢量版沿用了它们。原生标注对象与其文字是分开的对象，小样顶层数量不能只按标注对象计数。
- 该次参考外观使用尺寸线 RGB(0,128,255)、文字 RGB(23,112,175)，水平线距墙顶 30 API mm，竖线距左边 38 API mm，文字断线间隙 5 API mm，界线留隙和超出各 2 API mm。这些为本次样式参数，按当前参考调整。
- 每墙内容、宽度标注及可选高度标注形成墙面组，并给各对象稳定名称。标注应与墙面一起移动，尺寸文本仍可编辑。

### 估算前缀导致字体替代

该次创建 `约 3050` 后，即使传入 Arial，重开回读整段却为宋体。最终改为 Arial 支持的 `≈ 3050`，59 个宽度文字全部回读为 Arial 50 pt。若用户必须保留“约”，可独立创建中文前缀，或对数字字符范围单独设置默认字体；同样需要回读和视觉检查。不要因为创建参数是 Arial 就声称未替代，也不要为统一字体删掉估算含义。

## 原生尺寸接口的已知观测

先在独立小样中核实 `CreateLinearDimension`、`Dimension`、`Dimension.Linear` 和 `Dimension.TextShape` 的属性，再批量创建。记录小样文档身份，以便只清理自己的测试文档。

该次观测：

- PowerShell 直接以部分可选参数调用 `CreateLinearDimension`，出现“Cannot convert ... double to ... double”。改用 C# 包装层可创建：公开包装方法接收 `object`，在 C# 内转换为 `IVGLayer`、`SnapPoint`；PowerShell 直接传给公开的 `IVGLayer` 类型参数曾失败。程序集路径与接口 GUID 必须与安装版本匹配。
- 创建时传入 `Precision:0, ShowUnits:false`，以及后续通过 PowerShell 和 C# 设置相同属性，均未在该次实例生效；回读仍为 `Precision=2, ShowUnits=True`，显示 `6000.00 mm`。改变墙面尺寸或切换动态文本未解决。此为该次观测，不表示所有 X8/其他版本都不支持。
- 原生小样字号 50、Arial、默认箭头和细线可用，但不能据此推断精度、单位等其他属性也成功。相同设置已回读失败时，不继续批量试错；保存当前状态后换已验证的方法。用户明确要求原生关联标注时，报告限制并继续诊断，不能宣称手工组合是原生尺寸对象。

## 删除和群组的陷阱

CorelDRAW 在两子对象群组中删除一个子对象，可能将剩余一个子对象自动解组，使原父群组引用失效。该次先删旧标注再对旧父组调用 `UngroupEx()`，报“参考的对象不再存在”。

已验证修复顺序：

1. 保存检查点；保留待复用子对象的明确引用和身份。
2. 在父组仍完整时调用 `UngroupEx()`。
3. 删除旧标注。
4. 新建 `ShapeRange`，只加入仍存在的内容、可选高度标注和新宽度标注，再 `Group()` 并命名。
5. 重建索引；不继续使用已删除群组或含已删除成员的旧范围。

失败后先检查是否已保存和对象现状。只对本轮生成的输出恢复已知检查点；不丢弃用户其他未保存文档。

批量核查时缓存页面、Shapes 和按名称建立的索引，不在“每墙×每对象”循环中反复获取 `ActivePage.Shapes.Item(...)`。同一实例串行修改；分组后递归重建清单。

## 预览的导出范围

该次默认导出范围紧贴对象边界，容易裁掉数字、箭头的边缘；只指定像素宽高还可能改变预览比例。显式设置 `StructExportOptions.ExportArea` 并由同一矩形计算像素纵横比：

```powershell
# 已核实坐标的例子：CreateRect(x, y, Width, Height)，y 为下边界。
# 非零页面原点时，从当前页真实边界取 x/y，不机械使用 0,0。
$area=$app.CreateRect($page.LeftX, $page.TopY-$page.SizeHeight,
                      $page.SizeWidth, $page.SizeHeight)
$opt=$app.CreateStructExportOptions()
$opt.ExportArea=$area
$opt.SizeX=6000
$opt.SizeY=[int][math]::Round($opt.SizeX*$area.Height/$area.Width)
$opt.ImageType=[Corel.Interop.VGCore.cdrImageType]::cdrRGBColorImage
```

局部墙面/单行导出时，先明确选择范围，再对其外框四周留边；该次局部留边 20 API mm 可用。全页与局部均检查尺寸文字、箭头端点、界线和编号，不能仅看缩略图。PowerShell 5.1 脚本含中文路径、名称或符号时保存为 UTF-8 BOM，避免路径乱码。

## 保存后验收及本次证据

从保存、关闭、重开的输出核查：每面矩形的宽高和位置；行内编号顺序；宽度标注一面一个；高度仅出现于指定首面；数字与尺寸表一致；估算含义保留；字号、字体、旋转方向、文字溢出及旧标注残留。图形尺寸与字体检查应分别报告，字体失败不能误写成墙体几何发生变化。

本次输出 `墙面尺寸模板_全部墙面_标准尺寸标注.cdr`：59 个墙面组、59 个宽度标注、4 个高度标注（6-1、7-1、8-1、9-1）；全部尺寸文字 Arial 50 pt，比例 1:10，墙面几何保持不变，重开核查无问题，并导出了全图和首墙预览。属于该任务的保存后技术验收，不代表未来项目的通用参数或用户对整体方案的最终接受。
