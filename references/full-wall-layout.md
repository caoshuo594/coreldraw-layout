# 全单元、多墙与 AI 参考排版

用于“整个单元图文全部上墙”、连续转角墙、整套背景分配，以及把 AI 参考落实为可编辑 CDR。具体尺寸、字号、裁切权限和内容排除范围取本次用户要求，不从历史案例继承。

## 先确定源内容与墙面映射

1. 大纲按单元起止标题提取，保留单元导语、小节标题、正文、提示及案例。为段落建立稳定编号；换行规范化不能删除标点、词语或段落内容。排除项单独列出来源和依据；历史任务排除了“互动：”及其后说明，这不是新任务默认规则。
2. 配图递归检查群组和特殊容器，记录稳定编号、源对象/文件、原始比例、图说及所属小节。图片区分内容配图、背景、装饰，不能把所有位图数当作配图数。导出供排版时保留源对象关系，优先直接复制原对象。
3. 建立墙面表：墙号、实际宽高、源对象、展开坐标区间、入口、箭头几何、阅读顺序及其依据。箭头方向和观众阅读方向分别记录；不能把两者机械等同，也不能仅凭文件名、墙号或缩略图推断。用户最新的明确游线修订覆盖旧示意，但保留修订依据。
4. 建立“段落/图片编号 → 小节 → 墙号 → 目标对象名”的双向映射。分配表检查全文覆盖、图片唯一使用、跨墙承接和墙内小节顺序。用户要全部时，分配完成只是准备阶段，不是全墙交付。
5. 已确认样稿与未确认扩展分别标识。扩展或换背景前记录样稿图文、几何、字体及分组基线；只改授权部分，保存后与基线比较。

可用 JSON 保存映射，Markdown 供人工核对。不要把项目脚本中的墙号、图片数量或对象索引复制成通用默认值。

## 游线、转角和观看高度

- 多面墙可在一页连续展开，墙数不等于页数。分别记录页面边界与各物理墙区间；长墙预览拆成两张也不改变物理墙数和内容归属。
- 先将实际尺寸转换到经验证的 API 单位，再计算边界。按当前原点、坐标方向和地面基准求离地高度，不假定 BottomY 天然代表离地毫米。
- 对每面墙，正文、图片及图说的完整外框都应落在其可用区间内；连续背景可以跨墙，图文不能因在同一页而越过转角。图片加图说作为一个整体计算留白。
- 观看高度和转角安全距离取本次要求；检查所有图文对象的上下边界，而非只检查中心点。狭墙、长图说和末排是重点。
- 从右向左阅读时，标题、正文、小节及图片组的空间先后需一致；跨墙文字承接也要检查，不能只贴一条“右→左”标签证明顺序正确。
- 空间不足时调整图组、文字框和已授权字号/墙面分配，保留全文及原图。不得靠删文字、拉伸图片或越过转角解决。

## 背景与配图分别处理

用户要求整套背景时，先列出全部背景及墙面分配，核对实际使用的唯一背景集合。按内容和墙宽选择，允许重复的条件取任务要求；不能全墙沿用样稿背景却宣称使用整套。

“沿用已确认样式”应拆成字体层级、颜色、图组、留白等可复用规则，不能自动解释为重复样稿背景。背景文件夹中的图究竟是全部要用的素材还是备选方案，结合用户说明和清单确定；已说明全套要用时直接完成分配，不再当作备选只挑一款。

- 背景与图文分层。保存源文件名、像素尺寸、比例、源 SHA256、使用墙号及选择依据；已确认连续背景可按要求保留。
- 获准铺满背景时等比覆盖：`k=max(墙宽/原宽,墙高/原高)`，按 k 缩放后定位到裁切框；这是背景铺满规则，不代表配图也允许裁切。
- PowerClip 框与内部位图分开检查：框尺寸正确不能证明原图没变形；回读内部位图宽高比，并确认框内对象确为预期图片。配图若获准裁切，保留内部原图和可编辑裁切框；未获准的配图等比缩放、不裁切。
- 要求背景不变或无蒙版时，保留原背景，不添加遮色蒙版、色块面板、玻璃卡片或半透明层，也不整体调暗。通过授权范围内的字体、层级、间距和图组改善可读性。
- 仅换背景的修订，保存后比较图文内容和位置是否与已验收基线一致，同时重新检查新背景上的文字可读性。
- 用户纠正背景分配后，以修正并验收的 CDR 重新导出 AI 参照板；旧背景生成的 AI 稿标记为被替代，不混入本版最终参考。

## AI 参考落实为可编辑文档

AI 优化图用于探索层级、字号、间距、分组与视觉节奏。若需要完整内容和尺寸参照，先验证基础 CDR，避免把漏图、错墙或不正确背景传入参考。

- 参照板保留真实比例、墙号、阅读方向及分段关系。长墙拆板时标明左右半及实际整墙尺寸，避免被解释为新增墙或缺失内容。
- 超宽整墙生成出现漏栏时，可按小节边界拆成左右参考图，各图附墙号、半墙区间及配图清单，合并核对整墙覆盖。不要只裁掉漏栏后把余下画面当完整优化稿；拆板不改变基础 CDR 中的墙宽与分配。
- 提示词写清允许修改的版式，以及应保留的背景、图像身份、比例、全文和转角关系。用户要求先审提示词时，先交提示词，获准后再生成。
- 审查生成图是否镜像游线、移错标题、遗漏配图、生成虚构图片、加遮色面板或错误分墙。AI 图中的文字和尺寸不能代替源文及施工尺寸核对。
- 落实到 CDR 时重新使用原始图片及可编辑文字，按参考调整版式；整墙 AI 位图嵌入 CDR 不能当作可编辑交付。用户只要参考图时，不自动回改基础文档。
- 保留被新稿替代的版本并明确当前采用版；参考图未完成或未核查时如实标记状态。

## 保存重开验收与中断恢复

同一 CorelDRAW 实例只允许一个修改流程。中断后先确认进程、目标完整路径、Dirty 状态、已保存页及现存对象；停止本任务失效的自动化流程，不直接重跑整批、结束用户应用或关闭其余未保存文档。

恢复时逐页清点实际墙号、图文和映射记录，定位最后完整检查点。文件名写有“14面墙”、页数达到预期或旧脚本有完整末段代码，都不能证明最后几页已有内容；本案例曾留有空白末页及未完成的墙面记录。页数、物理墙数、已排完墙数分别记录。

保存后仅关闭已保存的输出，重新打开明确路径，由一个验证流程生成本次唯一 QA 记录。记录运行时间、输入/输出完整路径、CDR 文件大小/哈希、脚本版本及验证是否完整结束，避免混用旧 JSON、旧内存文档或不同版本结果。失败记录也写出错误和未完成检查；`issues=[]` 但验证中途异常仍不是通过。

应核查的实质内容：

| 检查 | 判定依据 |
|---|---|
| 比例与几何 | WorldScale、单位、页尺寸、实际墙区间、源墙宽高 |
| 大纲完整性 | 回查原始大纲，与段落映射及 CDR 实际全文比较；导语、提示、案例和排除项分别核对 |
| 图片完整性 | 稳定编号集合、每张使用次数、逐墙编号集合与对应图说；背景不计入配图 |
| 图片比例与裁切 | 内部位图比例、裁切框、主体及本次裁切许可 |
| 字体与可编辑性 | 实际字体/字号、混合范围、Text.Overflow、文字仍可编辑 |
| 空间与顺序 | 图文重叠、图说间距、离地高度、墙边/转角留白、各小节空间顺序及跨墙承接 |
| 背景与已确认部分 | 实际源背景集合、独立图层、禁用蒙版、基线内容及几何保留 |
| 最终可见效果 | 从重开的 CDR 导出全墙和细节预览；隐藏且不打印的辅助标注不混入上墙稿 |

普通群组遍历不能代替 PowerClip 等特殊容器检查。读取失败标记失败或未知。全文“包含”检查不足以证明段落次序、唯一性和墙面归属，需结合映射逐项核查。

若出现 `AssertionError: See QA JSON`、计数冲突或间距越界，检查 QA 对应的文件与运行时间，只修复确认的问题，然后保存、重开并运行一份新 QA。不得仅凭文件存在、导出 PNG、历史通过记录或修改后旧 JSON 宣称完成。

交付清楚列出可编辑 CDR、由重开文件导出的预览、逐墙内容/背景表、最终校验记录；分别说明基础版、样稿、AI 参考和用户确认状态。

## 2026-10 第七单元案例边界

本案例后期多背景版的磁盘记录显示：14 面墙分布在 12 页，前三面连续展开；66 张配图各一次，前三面 19 张、后 11 面 47 张；10 款背景均采用。保存重开 QA 为 `issues=[]`，正文与 DOCX 一致，已确认三墙及换背景前的图文几何保留。2026-10-17 回查时，最终 CDR 的 SHA256 与交付校验记录一致；这次技能更新没有重新运行 CorelDRAW 排版或验收。

历史过程中曾发生中断、64/66 张计数不一致和 7-7、7-10 转角留白不足；后期记录已通过，不能把早期失败 JSON 当最新状态，也不能省去新任务的独立验证。

本案例使用 1:10、墙高 3700 mm、主体图文离地 1200—2800 mm、转角每侧 200 mm；7-9 左→右，其余墙按最新游线右→左，单元标题导语最终在右侧入口墙。前三面保留获准的配图裁切框，后续新增配图不裁切；互动说明按当次规则不上墙。以上均是案例参数，不是其他项目默认值。
