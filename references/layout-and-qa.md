# 版式、尺寸及验收

## 任务参数中的易错含义

| 参数 | 必须区分 |
|---|---|
| 尺寸 | 实际毫米、图上毫米、API 回读数值 |
| 比例 | 例如1:10；回读 WorldScale，不只看模板名 |
| 图片宽500 | 实际500mm、图上500mm，还是参考的对象数值 |
| 字体5号 | 中文五号通常10.5pt，不是5pt；还要区分图上/实际字号 |
| 高度1100 | 底边离地、中心离地，或区域总高 |
| 图说 | 文件名原文、指定清单或CDR文字；扩展名/编号处理依要求 |
| 范围 | 一面样稿，或全部指定墙面 |

历史验证的 X8 毫米文档 WorldScale=10：实际尺寸÷10=API图上尺寸；7000×3700mm→700×370，实际图宽500mm→图上50mm。用当前模板及已知对象验证，不再手工缩放整页一次。

字体 pt 与几何单位不同。图上11pt标称字身约3.88mm，按1:10放大后实际约38.8mm；可见字高随字体变化。五号/11pt都不是通用默认值。

## 图片和图说

源像素宽高或未变形原对象给出比例 r=w/h；当前对象可能已变形，不能自动当作原始比例。

- 固定宽：新高=指定宽/r。
- 装入框：k=min(框宽/原宽,框高/原高)，原宽高同时乘k。
- 未获允许不裁切；允许裁切时保留原图副本，核查主体与说明对应。
- 图说LeftX=图片LeftX+(图片宽-图说实际外框宽)/2；多行文字另设置段落居中。
- 用图片底边与图说顶边定义间距，按当前坐标方向换算。紧贴不等于重叠，换行后重算下一排位置。
- 用“图片+图说”的总体边界排布，横竖图不强拉成同宽同高，视觉留白以预览检查。

比例可用相对误差 abs((新宽/新高)/r-1) 检查。误差容限依任务、单位及精度设置并记录，不为通过检查无限放宽。

## 内容和冲突

保留参考的标题层级、分组、阅读顺序及留白。装饰不覆盖图文、不承担事实说明。“只用有图文项目”是特定项目要求，不是通用筛选条件。

全文保留以源段落映射核对；明确选用/排除条目，不能默默删掉放不下的正文。边框/背景与文字的意图内叠加不等于冲突；图片遮正文、图说撞下一排、正文越界须修复。

## 保存后核对记录

记录源/输出/备份路径、应用版本、比例换算、逐页尺寸及实际尺寸、页数、已用项目及图文数量（定义计数层级）、全文差异、字体替代、溢出、图片比例、异常越界、特殊容器检查、预览路径和未核实项。

从重新打开的文件取数。属性读取失败记失败/未知，不当成0溢出。CDR内文字保持可编辑，整墙位图嵌入CDR不满足可编辑排版。

历史首墙为1页、6项目、8图、0文字溢出，重新打开后PNG哈希一致；仅证明该任务。不同PNG编码/元数据会改变哈希，当前应视觉比较，必要时比较解码像素，不以字节哈希作通用门槛。

## 回滚

停止后续修改，确定恢复检查点。有完整撤销记录时回撤已知命令组；否则从备份恢复到新文件，核对图文/页数/预览。不要只恢复磁盘版却让内存修改版再次覆盖。保留必要中间版本，不清除用户其他工作。
