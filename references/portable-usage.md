# 跨 AI 工具使用

## 安装与读取

- Codex：整个文件夹放入 `~/.codex/skills/coreldraw-layout`，重新加载技能或新会话调用 `$coreldraw-layout`。
- 支持SKILL.md的工具：整个文件夹复制到其指定技能目录，保留相对路径，按工具自身方式加载。
- 不支持技能发现的工具：直接让它读取本技能SKILL.md，按需读references；命令使用脚本绝对路径或切换到技能目录。

使用直接 COM 路径时不依赖 Codex 专用 MCP 或其他技能；使用统一 MCP 路径时按 [配套仓库](https://github.com/caoshuo594/coreldraw-mcp) 安装。agents/openai.yaml 是 Codex 界面元数据，其他工具可忽略。仅有云端聊天能力不能直接操作本机，需本地终端或执行桥接。

```text

参考/模板：[绝对路径，无则说明]

范围：[一面样稿或全部指定墙面]

顺序/分组：[本次要求]

先核实目标、建立可恢复副本、提取并抽查图文对应，再修改。

```

## 脚本边界

get-coreldraw-state.ps1是只读预检/基础清单工具，不是一键排版器，不创建、关闭、保存CorelDRAW文档。OutputPath只写新的JSON检查文件，拒绝覆盖现有路径。

inventoryCompleteForOrdinaryGroups仅表示普通Shapes群组遍历完成，不代表特殊容器、文本链、字形或视觉版式通过验收。读不到的字段记录为错误，不能理解为正常。修改脚本按当前文档生成，不套旧项目对象索引。

## 跨工具同步更新

用户要求同步本机多个工具时，扫描其指定盘符，区分实际用户技能目录与插件缓存、依赖源码、示例、备份和回收站。将整个技能文件夹同步到已确认的用户技能根目录；不能只复制 SKILL.md 而遗漏相对引用。工具有明确安装目录指引时遵循该路径，不把项目中的旧副本当作全局安装位置。

先比较已有副本并备份差异；真实路径相同的 Junction/符号链接保留，只写一次。按文件相对路径和 SHA256 核对所有目标，逐份运行可用的结构校验，并检查相对链接。保护目录或链接目标不可访问时记入覆盖限制，不宣称全盘无遗漏。同步文件成功与工具会话已重新加载是两件事；按工具需要刷新技能或新开会话。
