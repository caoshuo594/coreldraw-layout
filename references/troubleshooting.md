# 常见问题和恢复

以下来自本机X8历史操作，不是跨版本保证。先记录错误和检查点，不把排版扩大为系统维护。

| 现象 | 判断与处理 |
|---|---|
| 路径不可访问 / os error267 | 核查绝对路径、盘符及账户；可访问后再排版 |
| COM类未注册 | 核实注册入口、安装版本及主机位数，不猜其他版本号 |
| GetActiveObject无实例 | 未运行、ROT未注册、权限不同均可能，不等于未安装 |
| PowerShell7无GetActiveObject | 用Windows PowerShell5.1、64位STA |
| RPC_E_CALL_REJECTED / 80010001 | 检查弹窗和初始化；只读可有限重试，写操作结果未知时先查状态 |
| CopyToLayer跨文档失败 | 用源Copy→目标激活→Paste，核实新增对象 |
| ActiveShape / ActiveWindow为空 | 读明确返回对象或比较新增集合；保存和视图分开 |
| 中文字体替代 | 设置后回读，核查字体安装、混合范围和输出字形 |
| FindShapes返回0 | 核实过滤语义，直接遍历并递归群组，不断言空文件 |
| SVG背景缩放后尺寸错 | 查真实对象边界及画布外路径，viewBox不等于全部边界 |
| 批处理卡住、重复或半成品 | 停止失败批次，核实检查点及已写入对象，不并发开第二个脚本 |

同一只读检查有限重试2–3次后仍失败，转为检查应用/弹窗并报告阻塞。非幂等写操作不能按同样次数自动重试。不能为恢复连接默认杀用户进程。

## 首次开文档慢：先查打印机

历史症状是启动较快、首次打开任意文档时一直查找打印机。该次用户确认默认打印机改为Microsoft Print to PDF后解决；字体数量多不是字体故障的证明。

先只读检查默认/失效打印机及应用提示。更改默认打印机影响系统，仅在用户要求修复并授权对应操作时执行，普通排版不顺带更改。

## 字体索引重建：独立维护

仅当用户需要重建Corel字体索引且版本适用时：保存并正常关闭有关Corel程序；核实 `%APPDATA%\Corel\FontDatabase\V1`，改名为带时间戳的备份而非删除；启动已核实的X8 `Programs64\FontManager.exe`，等待新数据库生成并检查可用性。

历史安装根目录为 `C:\Program Files\Corel\CorelDRAW Graphics Suite X8`，换机器重查。重建可能重置添加目录/集合元数据，保留恢复备份，不删除字体文件。不能假定每台X8都有F8字体库勾选项。历史数据库文件数/大小不是验收标准；注册表字体项清理未证明是开文档慢的修复，不自动执行。
